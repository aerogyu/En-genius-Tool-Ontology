# 조사 양식 명세 (reference/SW조사양식_EnGenius_v1.0.xlsx)

> 이 문서는 원본 양식 파일에서 **자동 추출**했다. 실제 사내 양식은 이 원본을 일부 수정해 배포됐다 (담당 부서 → 연구소 24개 분야, 분류 드롭다운에 '설계-2D Layout' 등 추가). 따라서 적재기는 열 위치가 아니라 **헤더 이름**으로 매핑하고, 드롭다운 값은 **파일의 '선택지' 시트에서 읽는다**.

## 시트 구성

| 시트 | 역할 | 행 구조 |
|---|---|---|
| 작성안내 | 작성 규칙·작성자 정보 | 적재 대상 아님 |
| SW기본정보 | 분야별 SW 응답 1건 = 1행 | 1행 섹션 밴드, 2행 헤더, 3행 안내(회색), 4행 예시(주황), 5행부터 응답 |
| SW입출력 | 데이터 종류 1개 = 1행, SW ID 반복 | 1행 섹션 밴드, 2행 헤더, 3행 안내, **4~6행 예시 3줄**, 이후 응답 |
| 선택지 | 드롭다운 목록 원본 | 2행 목록 이름, 3행부터 값 |

> ⚠️ 양식 결함: 작성안내에는 두 시트 모두 '5행부터 작성'이라고 돼 있지만 SW입출력은 예시가 4~6행이다. 응답자가 5~6행 예시를 덮어썼거나 7행부터 썼을 수 있으므로, 예시 행은 **행 번호가 아니라 내용(템플릿 예시 값과의 일치)으로** 판별한다. 셀 서식(주황 배경)은 보조 신호로만 쓴다.

> SW ID는 '부서약칭-일련번호'로 분야마다 따로 매긴다. 따라서 **SW ID는 툴의 ID가 아니라 '분야별 사용 기록'의 ID**다 (같은 CATIA를 10개 분야가 적으면 SW ID도 10개).
