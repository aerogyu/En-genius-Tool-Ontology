# 조사 양식 v1.0 → v1.1 변경분 (2026-09-28, Leo 전달)

사내 배포 양식 v1.1 (`Tool조사양식_EnGenius_v1.1.xlsx`) 을 v1.0 (`SW조사양식_EnGenius_v1.0.xlsx`) 과 openpyxl 로 비교한 결과.
**응답 데이터는 없다** — 예시 행 2줄만 있고, 예시 행의 '실무 문의처' 두 칸은 저장 전에 `홍OO(내선 0000)` 으로 가렸다 (규칙 5).
openpyxl 재저장으로 드롭다운(데이터 유효성 확장)은 빠졋다 — 선택지 값은 `선택지(수정금지)` 시트가 정본.

## 1. 시트 이름 (전부 바뀜 — docs/09 #13 이 막고 있음: 현재 적재기는 시트명이 상수)

| v1.0 | v1.1 |
|---|---|
| 작성안내 | 작성안내 |
| SW기본정보 | **Tool 기본정보** |
| SW입출력 | **Tool 입출력** |
| 선택지 | **선택지(수정금지)** |

행 구조는 같다: 1행 섹션 밴드, 2행 헤더, 3행 안내, 예시 행(기본정보 4~5행 **2줄**로 늘었음 · 입출력 4~8행 **5줄**), 이후 응답.
기본정보 A열에 `No.` 가 생겼고 6행부터 1,2,3… 이 미리 채워져 있다 (빈 응답 행도 A열 값이 있음 → 빈 행 판정에 A열을 빼야 함).
입출력 `Tool명(자동)` 은 B9 이후 200행까지 VLOOKUP 수식이 미리 들어 있다 (값 없는 행의 수식은 빈 문자열).
