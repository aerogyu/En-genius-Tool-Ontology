# 04. 반입 목록

폐쇄망 반입은 심사 비용이 크다. **새 의존성을 추가하면 반드시 이 표에 라이선스와 함께 적는다.** 허용형 라이선스(Apache·MIT·BSD 계열)만 허용한다.
전이 의존까지의 실측 표는 `python -m engenius_onto licenses` 로 뽑는다 (금지 항목이 있으면 rc=1).

> **LinkML 과 rfc3987 (M0, 2026-09-24).** 사내에서 스키마를 수정·생성해야 하므로 LinkML 은
> 반입한다 (Leo 결정). 그런데 `linkml → jsonschema[format] → rfc3987` 이 **GPLv3+** 다
> (절대 규칙 4). rfc3987 은 jsonschema 의 URI 형식 검사용 선택 부품이고, jsonschema 는
> 이것이 없으면 **rfc3986-validator(MIT)로 자동 대체**한다 (`jsonschema/_format.py` 의
> `try: import rfc3987 / except ImportError:` 분기 — jsonschema 가 공식 제공하는
> `format-nongpl` 조합과 같다). 실측으로 두 환경의 결과가 같음을 확인했다 (부록 C).
> 그래서 **LinkML 은 반입하되 rfc3987 은 설치하지 않는다.** 규칙 예외를 둘 필요가 없다.
> 안전장치: `python -m engenius_onto licenses`·`doctor` 와 `tests/test_license_guard.py` 가
> rfc3987 잔존 시 실패한다.

## 5. 오프라인 설치 절차

사내 PyPI 미러(Nexus 등)가 있으면 거기 등록 요청이 가장 빠르다. **요청 목록에 rfc3987 은 넣지 않는다.** 없으면:

```
# 외부 PC (Windows 11 x64 · Python 3.10 — 사내와 같음). 2026-09-28 실행한 그대로:
#   1) 깨끗한 venv 에 requirements.txt 를 개발 venv 의 pip freeze 를 제약(-c)으로 걸어 설치 → pip uninstall -y rfc3987 → pip freeze > requirements.lock (90개)
#   2) wheel 수집 — pip download --only-binary 는 antlr4-python3-runtime 4.9.3 (sdist 만 있음) 에서 멈추므로 pip wheel 을 쓴다 (sdist 는 여기서 wheel 로 빌드)
pip wheel --no-deps -r requirements.lock -w offline/wheels
pip download --no-deps --only-binary=:all: pip setuptools wheel -d offline/wheels   # 사내 3.10.2 동봉 pip(21.2.4) 갱신용

# 사내 — offline/wheels 폴더 반입 후. 아래를 scripts\setup_offline.bat 이 그대로 한다 (README_offline.md 3장)
python -m venv .venv
.venv\Scripts\python -m pip install --no-index --find-links offline\wheels --upgrade pip setuptools wheel
.venv\Scripts\python -m pip install --no-index --no-deps --find-links offline\wheels -r requirements.lock
set PYTHONPATH=src
.venv\Scripts\python -m engenius_onto doctor      # [OK] 금지 패키지 없음 확인
```

- `--no-deps`: lock 에 전이 의존이 전부 적혀 있으므로 pip 가 jsonschema[format] 을 풀어 rfc3987 을 찾으러 가지 않게 한다.
- **우리 코드는 설치하지 않는다** (`PYTHONPATH=src` 로 실행). wheel 로 site-packages 에 넣으면 `config.py` 의 `REPO_ROOT = parents[2]` 가 `.venv\Lib` 를 가리켜
  `config\` 를 못 찾는다 (2026-09-28 실측). 설치형이 필요해지면 `ENGENIUS_ROOT` 환경변수 같은 우회를 config.py 에 넣는다.
- 인터넷이 되는 곳에서 `pip install -r requirements.txt` 로 설치했다면 **직후 `pip uninstall -y rfc3987`** 을 한다 (linkml 이 매번 다시 끌어온다).
- OS·파이썬 버전이 다르면 사내에서 설치가 실패한다 (가장 흔한 사고). 같은 환경을 만들 수 없으면 `--platform`, `--python-version`, `--only-binary=:all:` 옵션으로 받고, wheel이 없는 패키지는 따로 확인한다.
- `requirements.lock`은 `==`로 버전을 고정한다. 신청서 첨부 자료이자 환경 재현 기록이다.
- 반입 전 새 가상환경에서 `--no-index` 설치를 한 번 시험한다 (M5 완료 기준) — 6장에 기록.
