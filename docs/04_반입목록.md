# 04. 반입 목록

폐쇄망 반입은 심사 비용이 크다. **새 의존성을 추가하면 반드시 이 표에 라이선스와 함께 적는다.** 허용형 라이선스(Apache·MIT·BSD 계열)만 허용한다.
전이 의존까지의 실측 표는 `python -m engenius_onto licenses` 로 뽑는다 (금지 항목이 있으면 rc=1).

## 1. 툴 온톨로지 단계 (M0~M5)

| 항목 | 용도 | 라이선스 | 비고 |
|---|---|---|---|
| Apache Jena Fuseki | 그래프 저장소 | Apache 2.0 | zip 배포본. 설정 파일과 함께 반입 |
| Java 17 이상 | Fuseki 실행 | OpenJDK (GPLv2+CE) | 사내에 있으면 생략. Jena 5 계열 요구사항. zip 배포본(관리자 권한 불필요) 권장 |
| LinkML | 스키마 작성·생성·검증 (**사내에서도 수정·생성**) | Apache 2.0 | 전이 의존 포함 92개 (부록 A). **rfc3987 은 빼고 설치** — 아래 참고 |
| rfc3986-validator | rfc3987(GPL) 대체 — URI 형식 검사 | MIT | jsonschema 공식 `format-nongpl` 경로 |
| rdflib | RDF 처리·로컬 SPARQL 백엔드 | BSD-3 | LinkML 의존으로도 설치됨 |
| pydantic | 인스턴스 검증 (LinkML 이 생성한 클래스) | MIT | LinkML 의존으로도 설치됨 |
| openpyxl | 조사 엑셀 읽기·보고서 쓰기 | MIT | 사내에 있을 수 있음 |
| pandas | 표 처리 | BSD-3 | 사내에 있을 수 있음 |
| PyYAML | config/ 읽기 | MIT | |
| Protégé (선택) | 스키마 시각 검토 | BSD-2 | 데스크톱 앱 |

> **LinkML 과 rfc3987 (M0, 2026-09-24).** 사내에서 스키마를 수정·생성해야 하므로 LinkML 은
> 반입한다 (Leo 결정). 그런데 `linkml → jsonschema[format] → rfc3987` 이 **GPLv3+** 다
> (절대 규칙 4). rfc3987 은 jsonschema 의 URI 형식 검사용 선택 부품이고, jsonschema 는
> 이것이 없으면 **rfc3986-validator(MIT)로 자동 대체**한다 (`jsonschema/_format.py` 의
> `try: import rfc3987 / except ImportError:` 분기 — jsonschema 가 공식 제공하는
> `format-nongpl` 조합과 같다). 실측으로 두 환경의 결과가 같음을 확인했다 (부록 C).
> 그래서 **LinkML 은 반입하되 rfc3987 은 설치하지 않는다.** 규칙 예외를 둘 필요가 없다.
> 안전장치: `python -m engenius_onto licenses`·`doctor` 와 `tests/test_license_guard.py` 가
> rfc3987 잔존 시 실패한다.

M6 착수 시 이 패키지들도 `licenses` 명령으로 전이 의존까지 다시 확인한다.

## 3. 개발 전용 (반입 불필요)

pytest(MIT) 등 테스트 도구는 `requirements-dev.txt`에 두고, 사내에서 테스트까지 돌릴 경우에만 반입한다.

## 4. 실행 요건

- 파이썬 **3.10 이상** (MCP SDK·LangGraph 요구). **사내 파이썬 3.10.2** (Leo 확인 2026-09-24) — 개발 PC 도 3.10 (3.10.11) 가상환경으로 맞춘다.
- Java **17 이상** (Jena 5 계열 Fuseki)
- 사내 OS: Windows 로 가정 (M5 전 확인). 사내 라이브러리는 요청하면 대부분 추가된다 (Leo, 2026-09-24).

## 5. 오프라인 설치 절차

사내 PyPI 미러(Nexus 등)가 있으면 거기 등록 요청이 가장 빠르다. **요청 목록에 rfc3987 은 넣지 않는다.** 없으면:

```
# 외부 PC — 반드시 사내와 같은 OS·파이썬 버전
#   requirements.lock 은 rfc3987 을 뺀 환경의 pip freeze 로 만든다 (M5)
pip download --no-deps -r requirements.lock -d offline/wheels

# 사내 — offline/wheels 폴더 반입 후. --no-deps: lock 에 전이 의존이 전부 적혀 있으므로
#   pip 가 jsonschema[format] 을 풀어 rfc3987 을 찾으러 가지 않게 한다
pip install --no-index --no-deps --find-links offline/wheels -r requirements.lock
python -m engenius_onto doctor      # [OK] 금지 패키지 없음 확인
```

- 인터넷이 되는 곳에서 `pip install -r requirements.txt` 로 설치했다면 **직후 `pip uninstall -y rfc3987`** 을 한다 (linkml 이 매번 다시 끌어온다).
- OS·파이썬 버전이 다르면 사내에서 설치가 실패한다 (가장 흔한 사고). 같은 환경을 만들 수 없으면 `--platform`, `--python-version`, `--only-binary=:all:` 옵션으로 받고, wheel이 없는 패키지는 따로 확인한다.
- `requirements.lock`은 `==`로 버전을 고정한다. 신청서 첨부 자료이자 환경 재현 기록이다.
- 반입 전 새 가상환경에서 `--no-index` 설치를 한 번 시험한다 (M5 완료 기준).

## 부록 B. '확인' 항목 판단 근거 (반입 심사용)

| 패키지 | 메타데이터 라이선스 | 끌어온 경로 | 판단 |
|---|---|---|---|
| docutils | PD / PSF / BSD / **GPL** 복수 | linkml → sphinx-click → sphinx | 배포본 `COPYING.txt` 확인: GPLv3+ 는 `tools/editors/emacs/rst.el`(Emacs 편집기 확장) **한 파일뿐**이고, 설치 wheel 의 `RECORD` 에 해당 파일이 **없다** (0건). 설치되는 코드는 PD·BSD·PSF·ZPL — 전부 허용형 |
| certifi | MPL-2.0 | requests | 약한 copyleft (파일 단위 — 수정해 배포할 때 그 파일만 공개 의무). 수정·배포하지 않음. requests 를 쓰는 거의 모든 파이썬 환경에 들어 있는 CA 인증서 묶음 |
| fqdn | MPL-2.0 | jsonschema[format] | 〃. 호스트명 형식 검사 |
| tqdm | MPL-2.0 AND MIT | linkml → pystow | 〃. 진행 표시줄 |

MPL-2.0 은 GPL 이 아니지만 "Apache·MIT·BSD 계열" 에도 딱 맞지 않는다 — **심사 담당 판단 사항**으로
올린다. 참고: 셋 다 수정 없이 사용만 하므로 공개 의무가 생기지 않는다는 것이 일반적 해석이다 (법률 판단 아님).

## 부록 C. rfc3987 제거 후 LinkML 동작 대조 (M0 실측, 2026-09-24)

같은 시험 스키마(클래스 3·열거형 2·uri 슬롯·필수값·최솟값 포함)로 rfc3987 **있는** 환경과 **없는**
(rfc3986-validator 대체) 환경에서 LinkML 1.11.1 을 돌려 비교했다.

| 도구 | 종료 코드 | 결과 비교 |
|---|---|---|
| `linkml lint` | 1 / 1 (경고) | 동일 |
| `gen-owl` | 0 / 0 | 트리플 219개 **동형(isomorphic)** — 줄 순서만 다름 |
| `gen-shacl` | 0 / 0 | 트리플 94개 **동형** — 줄 순서만 다름 |
| `gen-pydantic` | 0 / 0 | 바이트 동일 |
| `gen-doc` | 0 / 0 | 바이트 동일 |
| `linkml validate` (정상 데이터) | 0 / 0 | 동일 |
| `linkml validate` (오류 5종) | 1 / 1 | 동일 — 열거형 위반 2·**URI 형식 위반**·최솟값·필수값 누락 전부 검출 |

- 줄 순서 차이는 GPL 과 무관하다: **같은 환경에서 두 번 돌려도** gen-owl·gen-shacl 의 출력 순서가
  바뀐다 (동형은 유지). → M1 에서 생성물을 커밋할 때 정렬(정규화) 직렬화를 거쳐야 git diff 가
  의미 있는 변경만 보여준다. M1 작업 항목으로 넘긴다.
- URI 형식 검사는 `tests/test_license_guard.py::test_linkml_uri_format_check_survives_without_rfc3987` 로 잠갔다.
