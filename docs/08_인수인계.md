## 6. 함정 기록 (다시 밟지 말 것)

작업 방식
- 여러 줄 편집 스크립트·생성기는 **Write 도구로 파일을 만들어 실행**한다. bash heredoc 안의 파이썬은 `\n`·따옴표가 붕괴한다
  (이 세션에서도 cli.py 에 `"\n"` 이 실제 개행으로 들어간 사고). 한 줄 치환은 Edit 도구.
- 파일은 LF 로 쓴다 (`newline="\n"`, `.gitattributes` 가 LF 기본·xlsx binary·bat crlf).
- `git diff --check` 는 `schema/generated/` 를 빼고 돌린다 (gen-doc 이 줄 끝 공백을 만든다 — 손대지 않는 생성물).
- Python 3.10: f-string 안에서 같은 따옴표 중첩 불가. 문자열 안 `\f` 는 폼피드 (`scripts\\fuseki_start.bat`).

LinkML·스키마
- 스키마를 고치면 `python -m engenius_onto schema` (생성물 드리프트는 `--check` 와 테스트가 잡는다).
- 클래스 이름 `Field` 금지 (pydantic.Field 를 덮어씀 → `ResearchField`, RDF 는 `eg:Field`).
- OwlSchemaGenerator 파이썬 API 기본값이 CLI 와 반대 — schema_gen 이 명시한다. identifier 슬롯은 eg:id 로 나와 OWL 충족 불가·SHACL
  무효가 되므로 후처리로 지운다. HermiT 는 xsd:pattern 의 `\d`·끝 `-`·앵커를 거부.
- YAML flow 매핑 `{description: ...}` 안에 쉼표가 있으면 따옴표 (LinkML 이 `PermissibleValue.__init__() got an unexpected keyword` 로 죽는다).
- 새 열거형을 추가하면 `tests/test_schema.py` 의 열거형 수·핵심 클래스·ObjectProperty 목록을 같이 고친다.

RDF·도구
- SHACL 은 Fuseki jar 의 Jena (`shacl_check`) — Windows 절대경로를 IRI 로 못 받아 임시 폴더 상대경로로 넘긴다. 검증 범위는
  survey ∪ derived (derived 만 돌리면 sh:class 위반).
- rdflib `Graph.value(None, p)` 는 None 을 돌려준다 — 직접 순회. `Dataset(default_union=True)` 의 DeprecationWarning 은 무해.
- openpyxl read_only 워크시트는 열 순회가 없다 — 행을 zip. NFKC 가 'ㆍ'(U+318D) 를 U+119E 로 바꾼다 — 구분자에 둘 다.
- 라이선스: linkml 이 rfc3987(GPLv3+) 을 끌고 온다 — 설치 후 `pip uninstall rfc3987`. `licenses` 명령·테스트가 감시.
